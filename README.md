# ⚽  World Cup EDA Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on  World Cup historical data using Python. The objective is to uncover meaningful insights about tournaments, teams, players, goals, and match outcomes through data cleaning, visualization, and statistical analysis.

The analysis demonstrates how data analytics can transform raw sports data into valuable business and performance insights.

---

## 🎯 Objectives

- Analyze historical FIFA World Cup data
- Explore tournament trends over different years
- Identify top-performing teams and players
- Study goal-scoring patterns
- Visualize important statistics
- Gain insights using Exploratory Data Analysis (EDA)
